# 🧠 머신러닝 분류 모델 보고서 - 고객 구매 데이터로 성별 예측 (분류 문제)

- 주어진 데이터는 백화점 고객의 1년 간 구매 데이터입니다.   
- 고객 3,500명에 대한 학습용 데이터(X.csv, y.csv)를 이용하여 성별예측 모형을 만들어보는 보고서입니다.    
- 이 보고서는 총구매액, 최대구매액, 환불금액 등 다양한 특성을 바탕으로 고객의 **성별(남/여)을 예측**하는 분류 모델을 설계하고, 여러 머신러닝 알고리즘을 비교 분석하여 가장 성능이 좋은 모델을 선정하는 것을 목표로 합니다.

분류 예측 문제를 해결하기 위해 데이터 전처리부터 모델 평가까지의 과정을 순차적으로 진행하였으며, 대표적인 머신러닝 알고리즘인 **Logistic Regression, Decision Tree, Random Forest, XGBoost**를 각각 적용하였습니다.

---

## 📊 프로젝트 개요

- **목표**: 고객 구매 데이터를 바탕으로 성별(0: 여성, 1: 남성)을 예측하는 머신러닝 분류 모델 개발
- **데이터 구성**: 총구매액, 최대구매액, 환불금액, 주구매상품, 주구매지점 등의 변수 포함
- **예측 대상**: `성별` 컬럼 (이진 분류)

---

## 🛠️ 분석 및 모델링 과정

### 1. 데이터 전처리
- 불필요한 변수 제거 및 결측치 처리
- 독립변수(X), 종속변수(y) 분리
- 학습 데이터와 테스트 데이터 분할 (`train_test_split` 사용)
- `StandardScaler`를 활용한 스케일링 진행

### 2. 모델링 및 성능 비교
#### 적용한 분류 알고리즘:
- **로지스틱 회귀 (Logistic Regression)**
- **의사결정나무 (Decision Tree Classifier)**
- **랜덤 포레스트 (Random Forest Classifier)**
- **XGBoost Classifier**

각 모델은 다음의 평가 지표를 기준으로 성능을 비교하였습니다:
- 정확도 (Accuracy)
- 정밀도 (Precision)
- 재현율 (Recall)
- F1 Score
- 혼동행렬 (Confusion Matrix)

---

## ✅ 모델 성능 요약

| 모델 | 정확도 | 정밀도 | 재현율 | F1 Score |
|------|--------|--------|--------|----------|
| Logistic Regression | 62.7% | 48.2% | 10.3% | 0.170 |
| Decision Tree | 56.1% | 41.5% | 42.9% | 0.422 |
| Random Forest | 61.9% | 48.1% | 28.4% | 0.357 |
| **XGBoost** | **62.9%** | **50.2%** | **39.8%** | **0.444** |

- 모든 모델 중에서 **XGBoost Classifier**가 가장 높은 성능을 보였으며, 재현율을 제외한 모든 기준으로 우수한 결과를 기록하였습니다.
- 다만, 전반적으로 모델의 성능이 높다고 보기 어려우며, **하이퍼파라미터 튜닝, 변수 선택, 교차 검증 등 추가적인 개선 작업이 필요한 상태**입니다.
