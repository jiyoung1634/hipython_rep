## 📊 데이터 분석 프로젝트 02: 전자상거래 상품 카테고리별 구매 트렌드 분석 보고서

Python을 활용해 **전자상거래 상품의 카테고리별 구매 트렌드**를 분석한 보고서입니다.

## 📊 머신러닝 실습 프로젝트 01: 고객 데이터 기반 성별 예측 분류 모델 보고서
고객 데이터를 기반으로 **성별(남성(1)/여성(0))**을 분류하는 머신러닝 모델을 제작한 보고서입니다.   
전처리, 스케일링, 훈련/테스트 분리 과정을 거쳐 Logistic Regression, Decision Tree, Random Forest, XGBoost 등   
4가지 분류 모델을 비교하고, 정확도, 정밀도, 재현율, F1 Score, 혼동행렬을 활용해 성능을 평가하였습니다.   
성능이 가장 우수한 모델을 선정하고, 개선 방향도 함께 제시했습니다.

> 📁 `머신러닝 보고서/` 폴더에서 확인하실 수 있습니다

## 📊 머신러닝 실습 프로젝트 02: 자전거(bike) 대여량 예측 모델 보고서
Kaggle의 [Bike Sharing Demand](https://www.kaggle.com/c/bike-sharing-demand/data) 데이터를 기반으로,  
시간별 자전거 대여 수요를 예측하는 다양한 회귀 모델을 구현하고 성능을 비교한 보고서입니다.  
EDA와 전처리를 수행한 후,  
선형 회귀(Linear Regression), 랜덤 포레스트 회귀(RandomForest Regressor),  
다항 회귀 모델, 규제 회귀(Ridge, Lasso, ElasticNet) 등 다양한 모델을 적용하여  
RMSE와 R² Score를 기준으로 예측 성능을 분석하였습니다.  
또한 모델별로 스케일링 여부, 교차 검증 등의 적용 유무에 따른 성능 변화를 함께 실험하였습니다.

> 📁 `머신러닝 보고서2/` 폴더에서 확인하실 수 있습니다
