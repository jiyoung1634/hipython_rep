# 🚴 자전거 대여량 예측 모델 보고서

> Kaggle Bike Sharing Demand 대회 데이터를 기반으로 다양한 회귀 모델을 활용하여 자전거 대여량을 예측하고 성능을 비교한 프로젝트입니다.

---

## 📂 프로젝트 개요

본 프로젝트는 자전거 대여 수요 데이터를 바탕으로, 다양한 회귀 모델을 활용하여 수요를 예측하고 각 모델의 성능을 비교 분석하는 데 목적이 있습니다.

- **데이터 출처**: [Kaggle - Bike Sharing Demand](https://www.kaggle.com/c/bike-sharing-demand/data)
- **목표**: 일자별/날씨별/온도별 자전거 대여량을 수치적으로 예측

---

## 🗂️ 데이터셋 정보

- 주요 변수:
  - `datetime`: 날짜 및 시간 정보
  - `season`: 계절 (1: 봄, 2: 여름, 3: 가을, 4: 겨울)
  - `holiday`: 해당 요일이 휴일인지 여부
  - `workingday`: 해당 요일이 주말이나 휴일이 아닌지 여부
  - `weather`: 날씨 상태 - 1: 맑음, 구름 약간, 부분적으로 구름, 부분적으로 구름
2: 안개 + 구름, 안개 + 깨진 구름, 안개 + 구름 약간, 안개
3: 가벼운 눈, 가벼운 비 + 뇌우 + 흩어진 구름, 가벼운 비 + 흩어진 구름
4: 폭우 + 얼음판 + 뇌우 + 안개, 눈 + 안개 
  - `temp`, `atemp`: 실제(섭씨)/체감 온도
  - `humidity`: 상대 습도
  - `windspeed`: 풍속
  - `casual` : 등록되지 않은 사용자가 시작한 대여 수
  - `registered` : 등록된 사용자가 시작한 대여 수
  - `count`: 총 대여량 (예측 대상)

---

## 🔧 주요 전처리 내용

- `datetime` 컬럼 제거
- `casual`, `registered` 컬럼 제거 (count = casual + registered이므로)
- 스케일링: 선형회귀모델 StandardScaler 적용

---

## 🤖 적용한 회귀 모델

| 구분 | 모델 종류 |
|------|-----------|
| 기본 회귀 | Linear Regression, Random Forest Regressor |
| 다항 회귀 | PolynomialFeatures + Linear Regressor / Random Forest |
| 규제 회귀 | Ridge, Lasso, ElasticNet |
| 스케일링 적용 | 다항 회귀 & 규제 회귀 + StandardScaler  |
| 교차검증 적용 | Cross_val_score 기반 Linear & RandomForest 회귀 |

## ✅ 결론

- 가장 좋은 성능을 보인 모델은 다음과 같습니다:
  - **다항 회귀 (선형 회귀 기반, degree=4)**  
  - **다항 회귀 + 스케일링 적용 모델 (degree=3)**
  - 두 모델 모두 R² Score가 약 **0.27**로 가장 우수했습니다.

- **교차 검증 적용 시** 성능이 오히려 감소하는 경우도 있었으며, 데이터의 시간적 특성과 복잡성에 따라 교차검증 방식 선택의 중요성이 확인되었습니다.

- 전체적으로는 **다항 특성 생성 + 적절한 스케일링**이 모델 성능 향상에 가장 효과적인 접근이었습니다.
